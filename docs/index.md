# 100 Days of ML Code — Documentation

This documentation consolidates the public components and example usage from the repository into one place. It covers data preprocessing and classical ML algorithms used across the lessons, with runnable examples and setup instructions.

Use this alongside the datasets under `datasets/` and the lesson notes in `Code/`.

## What is included
- Concise summaries of each component (lesson) and the key scikit-learn estimators it uses
- Minimal runnable Python examples for each algorithm
- Guidance on inputs/outputs and typical parameters
- Tips to avoid common pitfalls (e.g., train/test leakage, feature scaling)
